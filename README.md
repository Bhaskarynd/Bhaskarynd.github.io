# Bhaskar Yerramsetti — Portfolio

**Live portfolio:** https://bhaskarynd.github.io/

A modern, responsive portfolio for a Full Stack .NET Developer, with a photo, career and education timelines, five professional project summaries, technical skills, resume-listed certifications, and contact links.

## Source and maintenance

`index.html` contains the HTML, CSS, JavaScript, original supplied photo, and downloadable original resume in one portable file. The photo and PDF are embedded as data URLs. Google Fonts supplies DM Sans and Manrope, with local sans-serif fallbacks. There is no build step or dependency installation.

To update the website, edit `index.html` on the main branch. GitHub Pages publishes from main / root.

## Content provenance

Professional details and certification titles are drawn from the supplied resume and have not been independently verified. No credential dates, verification IDs, results, or metrics were invented. Enterprise project summaries describe the professional contributions listed in that resume. Employer application source code was not supplied and is not published. The C# controller snippet is clearly labeled as an illustrative example authored for the portfolio.
