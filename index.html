AN ENGINEERING PERSPECTIVE

Small interfaces.
Clear responsibilities.

My work uses dependency injection, asynchronous APIs, and separation of concerns to keep services understandable and maintainable.

Illustrative C# example — written for this portfolio to demonstrate these patterns.

View this portfolio’s source ↗
ProjectsController.csC#
// A focused endpoint. Dependencies injected.
[ApiController]
[Route("api/projects")]
public sealed class ProjectsController(
    IProjectService projects) : ControllerBase
{
    [HttpGet("{id:guid}")]
    public async Task<IActionResult> Get(
        Guid id, CancellationToken cancellationToken)
    {
        var project = await projects.FindAsync(
            id, cancellationToken);

        return project is null
            ? NotFound()
            : Ok(project);
    }
}
